# Project Introduction

Submitted to Quercus on behalf of the team (70–100 words).

Shoe Beta is a web app that helps climbers choose climbing shoe models and size ranges before trying them on in a shop. Users answer a short questionnaire about their foot shape, experience and climbing style, then get a ranked shortlist with the reasons for each shoe. Users can compare up to three models and search for nearby shops; signed-in users can also save their profile and shortlist and record fittings with private photos. The app is built with Next.js, TypeScript, Tailwind CSS, PostgreSQL with Prisma, Better Auth, DigitalOcean Spaces and the Google Places API.
